# SongMap Fixtures

Reference SongMap documents used for testing, validation and
documentation.

```text
fixtures/
└── v1/
    └── minimal.songmap.json
```

Every fixture in this directory must validate against the `songmap/v1`
specification (see `docs/specs/songmap/SPEC.md`).

Additional fixtures covering tempo maps, confidence variants, lyrics
and recordings with intros will be added as the specification evolves.
